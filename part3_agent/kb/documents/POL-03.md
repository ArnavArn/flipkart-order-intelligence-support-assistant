---
doc_id: POL-03
title: Electronics Return Window
category: returns
---
Electronics carry a 10-day window from delivery, but it covers replacement for a genuine
functional defect only, not a change of mind. A defective unit is swapped for an identical new
unit after a quality check confirms the fault. Electronics that power on and function normally
cannot be returned simply because the buyer no longer wants them. Sealed accessories and original
packaging must be returned along with the unit.
