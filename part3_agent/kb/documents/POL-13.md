---
doc_id: POL-13
title: Exchange and Size Replacement
category: exchanges
---
Exchanges are available only for apparel and footwear, and only for a different size or color of
the same product. Only one exchange is permitted per order line item, after which any further
change must go through the standard return process. The replacement item ships only after the
original item is picked up or handed over for reverse pickup. Exchange requests follow the same
7-day window as the category's return policy.
